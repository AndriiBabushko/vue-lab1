# Vue 3 Composition API Utilities

Цей файл містить детальні пояснення до утиліт, що використовуються в **Vue 3 Composition API** для управління реактивністю та іншими аспектами компонента.

## Helpers

### `useAttrs()`
`useAttrs()` дозволяє доступити атрибути, передані в компонент. Це особливо корисно, коли вам потрібно динамічно обробити або передати ці атрибути в дочірні елементи.

### `useSlots()`
`useSlots()` дає доступ до слотів компонента, що дозволяє працювати з переданим вмістом слотів.

### `useModel()`
`useModel()` надає доступ до моделі двостороннього зв'язку. Використовується для роботи з даними, що зв'язуються з компонентом через `v-model`.

### `useTemplateRef()`
`useTemplateRef()` дозволяє отримати посилання на елементи DOM, які визначені через шаблони компонента. Це корисно для прямої маніпуляції з DOM-елементами.

### `useId()`
`useId()` генерує унікальний ідентифікатор, який можна використовувати для створення унікальних ключів для елементів чи атрибутів у вашому компоненті.

## Реактивність: Утиліти

### `isRef()`
`isRef()` дозволяє перевірити, чи є значення реактивним об'єктом `ref`. Повертає `true`, якщо значення є реактивним `ref`.

### `unref()`
`unref()` використовується для отримання значення з `ref`. Якщо передано звичайну змінну, вона повернеться без змін. Якщо ж передано `ref`, повертається його значення.

### `toRef()`
`toRef()` створює реактивне посилання на властивість об'єкта. Це дозволяє створити реактивну змінну для конкретної властивості об'єкта.

### `toValue()`
`toValue()` дозволяє отримати значення з `ref` або інших реактивних об'єктів, де це потрібно. Це корисно для розкриття значень реактивних об'єктів.

### `toRefs()`
`toRefs()` перетворює всі властивості об'єкта на реактивні посилання. Це корисно для передачі об'єктів через компоненти без втрати реактивності.

### `isProxy()`
`isProxy()` перевіряє, чи є об'єкт проксі. Це важливо, коли потрібно перевірити, чи є об'єкт частиною реактивної системи Vue.

### `isReactive()`
`isReactive()` перевіряє, чи є об'єкт реактивним. Повертає `true`, якщо об'єкт є частиною реактивної системи Vue.

### `isReadonly()`
`isReadonly()` перевіряє, чи є об'єкт тільки для читання, тобто не можна змінювати його значення.

## Реактивність: Основи

### `readonly()`
`readonly()` створює реактивний об'єкт, який не можна змінювати. Це корисно для створення даних, які повинні бути тільки для читання.

### `watchPostEffect()`
`watchPostEffect()` дозволяє спостерігати за реактивними змінами після того, як всі ефекти були виконані. Це дає більше контролю над послідовністю ефектів.

### `watchSyncEffect()`
`watchSyncEffect()` спостерігає за реактивними змінами синхронно. Це дозволяє вам реагувати на зміни реактивних даних негайно, без відстрочки.

## Реактивність: Розширено

### `shallowRef()`
`shallowRef()` створює реактивне посилання, але лише для самого об'єкта. Властивості об'єкта не будуть реактивними.

### `triggerRef()`
`triggerRef()` використовується для вручну активації оновлення для `ref`. Це дозволяє вам змінювати значення `ref` і спонукати до оновлення.

### `customRef()`
`customRef()` дозволяє створювати власні реактивні об'єкти з налаштованими методами для читання та запису значень. Це дозволяє вам контролювати, як відбуваються зміни.

### `shallowReactive()`
`shallowReactive()` створює реактивний об'єкт, де тільки сам об'єкт є реактивним, а його властивості — ні.

### `shallowReadonly()`
`shallowReadonly()` створює лише поверхнево реактивний об'єкт, де сам об'єкт є тільки для читання, але його властивості можуть бути змінені.

### `toRaw()`
`toRaw()` дозволяє отримати «сирий» (не реактивний) об'єкт з реактивного об'єкта. Це корисно, коли вам потрібно доступити оригінальний об'єкт без реактивності.

### `markRaw()`
`markRaw()` позначає об'єкт, як такий, що не має бути реактивним. Це може бути корисно для оптимізації, коли ви знаєте, що об'єкт не потребує реактивності.

### `effectScope()`
`effectScope()` дозволяє створювати окремі області ефектів, що дозволяє групувати і керувати реактивними ефектами в межах певної області.

### `getCurrentScope()`
`getCurrentScope()` дозволяє отримати поточну область ефектів, якщо вона існує. Це корисно для управління ефектами в складних структурах.

### `onScopeDispose()`
`onScopeDispose()` дозволяє зареєструвати функцію для виконання при видаленні поточної області ефектів. Це може бути корисно для очищення ресурсів або відписки від спостережень.

Ці утиліти допомагають створювати більш гнучкі і ефективні компоненти за допомогою Vue 3 Composition API, з можливістю налаштування реактивності та управління станом компонентів на високому рівні.
